# LYRICKEY — 노래 가사 타자

한국어 노래 가사 타자 연습을 위한 정적 웹사이트 MVP입니다.

## 실행하기
- GitHub 저장소에서 `index.html`을 열거나 GitHub Pages로 배포할 수 있습니다.
- 별도의 패키지 설치나 서버가 필요하지 않습니다.
- YouTube 플레이어는 사용자가 입력한 공식 영상 URL을 임베드합니다.

## 현재 구현
- 반응형 UI (PC/모바일)
- 연습 문장 목록 및 난이도 필터/검색
- 타자 입력, 진행률, 정확도, 분당 입력량 표시
- 연습 문장 직접 변경
- YouTube 영상 URL 연결 및 임베드 플레이어

## 현재 한계
- 곡 목록과 문장은 데모용 샘플이며 실제 K-pop 가사나 음원을 포함하지 않습니다.
- YouTube 영상은 플레이어에서 사용자가 직접 재생해야 합니다. 타자 완료로 영상 재생을 잠금 해제하거나 자동 재생하지 않습니다.
- 실제 가사/음원을 서비스하려면 해당 콘텐츠의 이용 권리를 별도로 확인해야 합니다.
- 통계는 현재 브라우저 세션 내에서만 유지되며 계정/서버 저장은 없습니다.
